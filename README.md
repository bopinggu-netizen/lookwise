# 素颜颜值参考评分

基于 Next.js 15 + Tailwind CSS 4 的颜值参考网站。上传正脸素颜照后，在浏览器本地进行质量检测与评分（照片不上传服务器）。

## 功能

- 上传 / 拖拽正脸素颜照片
- 质量检测：美颜、滤镜、浓妆、模糊、光线、遮挡、多人、正脸识别
- 通过后给出 **4.0–7.0** 颜值参考分及维度分析（普通人区间）
- 分档：普通 → 普通偏上 → 小美/小帅 → 明显好看 → 班花班草 → 普通人高颜值 → 顶美顶帅

## 运行

需安装 [Node.js](https://nodejs.org/) 18+。

```bash
cd beauty_score_web
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

## 说明

检测与评分基于 Canvas 图像启发式算法，在本地模拟专业检测流程，仅供娱乐与自我参考，不代表任何权威认定。
